# 动作与视觉验收

适用于修改自动演示的交互编排、鼠标、消息流程，或真实前端沙盒的模拟行为。选择本次受影响的检查，不必每次重跑整套。

## 在真正展示的页面上检查

确认宿主 URL、嵌入 iframe 的 URL 和实际产物版本。静态内嵌应用可能需要独立重建，宿主 HMR 成功不代表 iframe 里的代码更新了。使用当前环境允许的浏览器/原生应用工具，不绕过其限制。

先观察一遍完整流程，再对穿帮点采样。不要以一张完成态截图证明中间操作正确。鼠标动画的目标应取当前 DOM 的可见元素或文字范围；跨 iframe 时要在正确 frame 内测量。

## 自动演示的可观察断言

| 边界 | 需要看到的证据 | 常见失败 |
| --- | --- | --- |
| 开始输入前 | 指针已进入输入框，点击结束，演示焦点/插入符出现 | 时间到了就打字，鼠标还在别处 |
| 输入进行中 | 两次采样中文字变长、焦点仍在、指针坐标不变 | 输入时重新寻路或随机漂移 |
| 发送 | 输入完整，指针到按钮，点击之后才出现用户消息 | 字还没打完就发出完整气泡 |
| 链接预览 | 点击帧指针在链接文字内，预览尚未出现；随后才新增内部标签 | 取整行中心点，点击空白也跳转 |
| 暂停/恢复 | 暂停时文字、指针、步骤不再推进；恢复无瞬移 | 主时钟停了，WAAPI 仍在跑 |
| 重播/循环 | 清理旧到位记录和旧动画，按相同因果链重新开始 | 相同 selector 没发新事件而卡住，或旧事件跳过聚焦 |
| 目标晚出现 | 在前置条件处等待，目标就绪后再移动和点击 | 固定 timeout 到点后假装成功 |
| 缩放/手机端 | 指针与内容同步缩放；文本、弹窗、过程块不意外溢出 | 视觉缩小了，坐标仍是原来的页面像素 |
| reduced-motion | 稳定且能表达能力的静态状态 | 停在空白、等待中或动画半途中 |

比较静止坐标允许合理的亚像素误差，不要求字符串完全相同。判断落点应使用指针尖端，而非整个指针图形的中心；点击文字链接应使用文字边界，而非包含它的整行矩形。

可复用的采样思路：

```text
重播指定场景
等待进入输入阶段
采样 A：输入内容、焦点、指针位置
在同一输入阶段稍后采样 B
断言 B 内容比 A 长，焦点仍在，指针尖端位置近似不变

等待链接点击阶段
断言 指针尖端在链接文字边界内 且预览尚未打开
等待点击结束
断言 新的内部预览标签及对应内容出现
```

时序采样尽量在同一次受控工具执行中串起操作，或等待可观察状态。分散在多轮模型调用之间的“睡三秒再截图”包含推理、调度与传输延迟，可能已经错过目标阶段。固定短等待仅用于定位已知关键帧，实际验收仍看状态；能写自动回归时优先按状态等待。

暂停可以冻结待检查的关键帧，但不能把主动暂停造成的静止误报成“输入时鼠标不会动”。验证输入静止要在播放中观察文字增加，再比较指针位置。

## 真实前端沙盒的行为边界

针对改动选择真实路径检查：

- 发送 → 流式更新 → 完成 → 切走再打开，同一消息和工具状态保持一致。
- 文件目录 → 打开文件 → 终端/工具修改 → 再读取，内容与版本符合模拟模型。
- 目录卡片 → 详情 → 安装/授权/管理，状态来自同一实体而非各页面硬编码。
- 内部 localhost 链接打开约定的模拟页面，而不是误指向访问者机器上的真实端口。
- 新页面加载按演示约定重置状态；沙盒修改不污染宿主登录态、偏好或缓存。
- 未支持的 API/传输没有意外连接真实服务，也没有空成功掩盖错误。

适合新增测试的是这些可观察回归和生命周期边界，不是固定文案、CSS 字面值或对实现数组再抄一遍的断言。

## 交付时如何表述

分别说明构建/类型检查、模拟层测试、实际浏览器观察做到了哪一步。产物构建通过不等于服务端功能真实可用；按源码简化渲染不等于复用了完整产品渲染器。报告验证证据和未覆盖边界，不把调参感受写成测试结果。
