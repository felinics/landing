# Where can I use Memoh?

Help Center › Getting started · https://memoh.ai/help/getting-started/which-platforms

- **Desktop (recommended)**: macOS (Apple Silicon & Intel), Windows and Linux — see the [download page](https://memoh.ai/download).
- **Web**: [app.memoh.net](https://app.memoh.net).

Every entry point talks to the same agent with the same memory — pick up the conversation from anywhere.
