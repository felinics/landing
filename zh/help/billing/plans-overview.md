# Memoh 有哪些订阅计划？

帮助中心 › 订阅与计费 · https://memoh.ai/help/billing/plans-overview

Memoh 提供三档订阅：

- **Go**：从日常对话和轻量任务开始；
- **Pro**：为日常工作和持续运行的 Agent 准备；
- **Premium**：为更复杂的任务提供更多算力和空间。

订阅同时包含 **token 额度（credits）**与**云电脑资源**：各档位对应不同的 CPU 核数、内存、存储空间与每月 credits 额度，最新规格与价格见[定价页](https://memoh.ai/#pricing)。
