# Memoh 和普通 AI 聊天助手有什么区别？

帮助中心 › 开始使用 · https://memoh.ai/help/getting-started/how-is-memoh-different

传统聊天助手只在你打开窗口时"存在"；Memoh 的 Agent 拥有一台持续运行的云电脑，因此：

- **有电脑**：它有真实的桌面、文件和网络，能实际打开网站、安装依赖、运行代码、给你预览，而不只是输出文字；
- **一直在**：跑在云端，你的电脑关了它也在；定时任务和周期自检不需要你去触发；
- **会主动**：有重要的事，它会先发消息给你；
- **记得住**：会话不清零，记忆跨渠道共享，随时接着上次聊的继续。
