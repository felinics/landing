# Can I develop and preview apps on the cloud computer?

Help Center › Cloud computer & workspace · https://memoh.ai/help/cloud-computer/develop-and-preview

Yes. Writing code, installing dependencies and running dev servers all happen on the cloud computer — nothing to set up on your own machine.

When the agent starts a dev server, it hands you a localhost link; click it to open a live preview in a new Memoh tab that updates as the code changes.
