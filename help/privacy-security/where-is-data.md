# Where is my data stored?

Help Center › Privacy & security · https://memoh.ai/help/privacy-security/where-is-data

Your sessions, memory and workspace files are stored on Memoh's cloud infrastructure, isolated per Bot.

For the details of how data is handled, read the [privacy policy](https://memoh.ai/legal/privacy) and the [cross-border data transfer terms](https://memoh.ai/legal/cross-border).
