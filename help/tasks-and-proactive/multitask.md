# Can it run multiple tasks at once?

Help Center › Scheduled tasks & proactive messages · https://memoh.ai/help/tasks-and-proactive/multitask

Yes. Tasks run **asynchronously** in the cloud: hand one over, close the page, and the agent reaches you through your chosen channel when it finishes or needs a decision.

Multiple tasks move in parallel, and for stronger isolation you can create separate Bots for separate jobs — each with its own cloud computer and workspace.
