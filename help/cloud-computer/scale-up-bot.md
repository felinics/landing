# Can I add more resources to a Bot's workspace?

Help Center › Cloud computer & workspace · https://memoh.ai/help/cloud-computer/scale-up-bot

**Right now, scaling up means upgrading your plan.** The cloud computer's CPU cores, memory and storage follow your plan's specs — buying extra resources à la carte isn't supported yet.

In practice:

1. Upgrade to a higher tier (Go → Pro → Premium) under **Settings → Subscription**.
2. Upgrades take effect **immediately**, prorated for the rest of the billing cycle.
3. Once active, the Bot's cloud computer picks up the new specs automatically — files, dependencies, sessions and memory all stay in place, **no migration or rebuild needed**.
4. Higher tiers also come with a larger monthly credits allowance.

See the [pricing page](https://memoh.ai/#pricing) for a spec-by-spec comparison. Per-resource add-ons and per-Bot upgrades aren't available yet; if your workload outgrows the top tier, contact [support@memoh.net](mailto:support@memoh.net) to talk options.
